## Critical Path

The following tasks are on the critical path - delays will impact the event:

1. **TRU Approval** (Week 1) → Cannot proceed without permission
2. **Core Team Assembly** (Week 2) → All other recruitment depends on this
3. **Music Director Confirmed** (Week 2) → All rehearsals depend on this
4. **Wardrobe Production** (Week 4-5) → Must be complete before dress rehearsal
5. **Technical Rehearsal** (Mar 7) → Final venue coordination
6. **Dress Rehearsal** (Mar 12) → Last chance to identify issues
