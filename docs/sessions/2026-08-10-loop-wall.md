# 2026-08-10 — The Wall: Loop Soul's guest gallery on moments (PR 2)

Branch `claude/loop-soul-mobile-app-54086c`. Goal: the moments → Loop Soul
integration, on a phone, ready for a 75-person test event — guest photo/clip
sharing (#usergeneratedcontent), filters (Pose Studio → post), live gallery
curation, and admin moderation.

Design rationale: [docs/decisions/loop-wall-on-moments.md](../decisions/loop-wall-on-moments.md).

## What shipped

**Guest side**
- **The Wall** — shared, near-live gallery (polls every 15 s), 2-col grid,
  full-screen viewer (X-close, no drag — per owner UX prefs), share sheet.
  New tab in the Pose Studio shell inside the gated Portal; camera-roll
  uploads with client-side downscale to 2048 px JPEG (also normalizes HEIC).
- **Pose Studio → Wall** — "Post to the Wall" on the photo result; per-item
  "Wall" button in the on-device gallery (covers clips too). Only inside the
  Portal (`wallEnabled`); the public `/loop/pose` is unchanged.
- **Legacy** — placeholder cards replaced: Iconic Moments (admin-curated,
  public) + The Vault (all Wall shots, attendees only — event-code gate reused
  with a new `vault` tone).

**Admin (`/loop/admin`)**
- **The Wall — moderation & Iconic Moments**: Pending/All/Iconic/Hidden
  filters; approve / hide / feature (✦) / delete per shot, phone-sized.
- **Event codes — generate & issue**: bulk-mint (default 75), redeemed
  stats, copy-unused, per-code tap-to-copy. Backlog list trimmed accordingly.

**Access model** (per owner: tickets are Loop Soul's; moments media is for
attendees): full Wall read + post require a redeemed event code (`ls_voter` →
`event_holders`); posting additionally requires phase `live` (admin exempt);
Iconic Moments (`?featured=1`) is the only public cut.

## Discoveries / gotchas

1. **`media.odubo.studio` is NXDOMAIN** (lapsed domain) — every public R2 URL
   in the moments stack is currently dead in prod. The Wall therefore serves
   media through `/api/loop/gallery/media/<key>` → 302 to a **presigned R2
   GET** (the StorageService support that was never wired). Works with or
   without the domain. Existing moments pages still use the dead base URL —
   known issue, out of scope here.
2. **Remote D1 schema drift vs migration files**: `galleries` stops at
   migration 125 (no `is_permanent`/`content_rights`/`expires_at` — 133 never
   applied remotely); `gallery_photos.moderated_at/by` already existed
   out-of-band. `ensureLoopGallery` inserts only columns that exist remotely.
3. **Migration 144 is owned by the open Journal PR (#4)** and already applied
   remotely — this branch uses 145. Remote apply done 2026-08-10 via the
   runner script (only `featured` + index were new).
4. Worktrees have no `node_modules`; `npm run build` works via parent-dir
   resolution but **Turbopack panics** ("Next.js package not found").
   Symlinking the main checkout's `node_modules` + `npx next dev` (webpack)
   works.
