# 2026-08-11 (later) — Pass sales live, readable overlays, one media system

Branch `claude/loop-redraw-poster-studio` → PRs #11–#14, all merged to prod.

## Pass sales are live

- Shopify Admin API access via the legacy custom app **"integration"**
  (`SHOPIFY_ADMIN_ACCESS_TOKEN`). Scopes granted: products, inventory, orders,
  publications, discounts, price rules, draft orders, reports, read_all_orders.
  **No `read_locations`** — read inventory levels through
  `productVariant.inventoryItem.inventoryLevels` instead of `locations`.
- Product created by API: *Loop Soul — Volume 1 Pass*, **$20 CAD**, SKU
  `LOOP-PASS-VOL1`, 75 tracked, `requiresShipping: false`, ACTIVE, published to
  Online Store + Shop + both headless channels
  (product `9530389397717`, variant `54476588974293`).
- `orders/paid` webhook registered by API to the prod endpoint.
- **Gotcha that cost a cycle:** API-registered webhooks are signed with the
  registering **app's API secret key**, not the store notification secret.
  Secret now lives in `loop_settings.pass_webhook_secret` (PR #11) and is
  masked out of admin API responses (PR #12).
- Verified on prod with a signed simulated order: code minted + emailed,
  retry idempotent (`anyNew:false`), capacity reads the ledger. Mode flipped
  to `shopify`; poster Get Pass → real checkout.
- **`EMAIL_MODE` is still unset in prod → mock emails.** Owner must set
  `EMAIL_MODE=live` on Vercel before announcing.

## Readable overlays + the pass in the open (PR #13)

- `.loop-glass` was a 16%-opacity tint; now ~0.96 alpha in both modes (blur =
  depth, not transparency). New `.loop-muted` (color-mix 78% foreground)
  replaces opacity-60/70 washes; new `.loop-panel` for solid cards.
- Poster shows **price · passes left · date · doors · venue**; Get Pass opens a
  full details sheet (includes, how-it-works, multi-pass note) with a pinned
  checkout rail. `pass_price` / `pass_currency` are settings, captured by
  Detect.

## One media system (PR #14)

- **New:** `src/lib/loop/media/types.ts` (`MediaItem`),

  counter + caller-supplied `ViewerAction[]`).
