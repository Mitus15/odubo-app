# 2026-08-24 — Loop Soul is the album; Volume 1 moves to Sept 26

Two jobs: establish that Loop Soul *is* an album, and decide what the night now
is and what the marketing assets should say.

## What was decided

| | |
|---|---|
| **The date** | Sat **26 September 2026** (was Sept 12) |
| **The credit** | The record is by **Mani Odubo** (was seeded "Mitus"). Odubo stays the presenting studio |
| **Volume ↔ track** | **Loose** — usually a track, never a rule. The layout engine is not taught the tracklist |
| **The domain** | Coming later → the printed URL becomes a **setting**, never a constant |
| **Entry** | **Free.** Tiers parked deliberately (item 22) to avoid scope creep |
| **The anthem** | **Parked** for Vol 1; returns after the event as the **tracklist vote** |
| **The audience** | Closed circle — register + attend; registration closes on the night and never reopens |

Full reasoning: [loop-soul-is-the-album.md](../decisions/loop-soul-is-the-album.md).

## Why the date moved

At 19 days out: **0 passes sold, 0 RSVPs, phase `pre`, nothing printed**, and the
"announce week of Aug 18" window had passed in silence. Read as a premise
failure rather than a marketing one — a $20 party with a band has no reason to
exist on one particular Saturday; the first play of an unreleased record does.

## What shipped

**The album, asserted**
- `docs/decisions/loop-soul-is-the-album.md` — the canonical statement.
- Brand doc: the "Album artwork" colour exception renamed to **"Quoted
  artwork"** (it always meant *other people's* sleeves, and would have read as
  the opposite now that Loop Soul has its own), plus a new "The album" section.
- Show flow addendum: the band's peak set is the album; one track recorded live.
- `scripts/loop/assert_album_identity.ts` — **run against production**: set
  `artist_name` → Mani Odubo, and wrote the **first four `release_links` rows**
  (`loop-event`, `shopify-product`, `journal-issue`, `poster-kit`). Migration 155
  had modelled the album owning all of these since it landed; the claim had
  lived only in the DDL. Verified idempotent.
- `/loop` metadata now names the record ("Loop Soul — the album").
- Get Pass modal: "The record, first" and "In the circle, for good" replace the
  anthem promise.

**The destination, made data**
- `src/lib/loop/publicUrl.ts` + `loopSetting.ts` — `loop_settings.public_base_url`
  is one value both runtimes read. Per-piece defaults, placement tags (`?p=`).
- **Removed the hardcoded `odubo-studio-app.vercel.app` from the print kit**
  (`poster-kit.ts:50,61`), which violated the locked never-hardcode-a-domain
  rule. The kit now **refuses to render** without a base URL — verified.
- **Fixed a silent print-killer**: `compose.ts` fell back to the bare relative
  string `"/loop"`, encoding a QR no phone can resolve. It now throws, matching
  the engine's existing "refuse rather than overlap" philosophy.
- Studio: base URL + placement + per-piece override, and it says out loud when
  it is using the browser's origin instead of the configured one.

**The assets**
- Date → Sept 26 in `hub.ts` and the kit.
- New **`flyer`** size (half-letter 1650×2550 @300dpi) — the hand-out piece for
  the Sept 11 barbecue. Picked up automatically by the studio and the tests.
- New optional **`record`** row on the poster (`THE ALBUM · FIRST PLAY`) — its
  own asserted, non-overlapping row; optional because volume↔track is loose.
- Price is now **one setting** shared by the front door and the print kit
  (`src/lib/loop/priceLabel.ts`); unset/zero reads `FREE ENTRY`. Opening the
  door is one field, and the poster can never contradict checkout.
- `ANTHEM_ENABLED = false` in `content.ts` parks the module, its pass promise
  and its poster family without deleting anything.
