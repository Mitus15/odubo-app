# The Hub - Staff Handbook

## Welcome to The Hub

The Hub is your central command center for managing content, events, commerce, and more. This guide will help you navigate the system and understand your access based on your role.

## Accessing The Hub

1. Visit `/admin-v2` on the website
2. Log in with your team credentials
3. You'll see your personalized dashboard based on your role

## Understanding Your Role

Your access to different features depends on your assigned role. Here are the available roles:

| Role | What You Can Do |
|------|-----------------|
| **Administrator** | Full access to everything |
| **Social Media Manager** | Social distribution, content viewing, analytics |
| **Content Editor** | Create and edit media content, manage moments |
| **Merchandiser** | Manage products, inventory, view analytics |
| **Customer Service** | Handle support tickets, view orders |
| **Developer** | System monitoring, technical maintenance |
| **SCM Manager** | Supply chain, vendors, event logistics |
| **Accountant** | Financial reports, order viewing |
| **HR Manager** | Team management, internal communications |
| **Marketing Manager** | Campaigns, social, analytics, events |
| **Project Manager** | Project coordination, cross-team oversight |

## Navigation

### On Desktop
- **Left Sidebar**: Always visible with all modules

## Content Hub

The Content Hub is where all media lives.

### Videos
- View all uploaded videos
- Toggle between grid and list view
- Filter by status (All, Published, Draft)
- Click a video to edit details

### Clips
- Short-form content for the feed
- See engagement metrics (views, shares)
- Sort by "Most Recent" or "Top Performing"
- Link clips to products for shopping

### Music
- Manage albums, EPs, and singles
- Upload tracks and cover art
- Set featured albums

### Moments (Event Galleries)
- Create event galleries for photo collection
- Set event codes for attendees
- Schedule gallery open/close times
- Toggle "Featured" to highlight events
- Mark events as "Persistent" for ongoing galleries

## Creating Event Galleries

1. Go to **Content > Moments**
2. Click **Create Event**
3. Fill in:
   - **Title**: Event name
   - **Event Code**: Unique code attendees use to join
   - **Start/End Date**: When the gallery accepts uploads
   - **Persistent**: Check if gallery stays open indefinitely
   - **Featured**: Check to highlight on public page
4. Click **Create**

### Sharing Event Codes
- Give attendees the event code
- They visit `/moments` and enter the code
- Or share direct link: `/moments?code=YOURCODE`

## Common Tasks

### Adding a Video
1. Go to **Content > Videos**
2. Click **Add Video**
3. Upload your file
4. Fill in title, description, type
5. Set visibility (Public/Private)
6. Save

### Featuring an Event Gallery
1. Go to **Content > Moments**
2. Find your gallery
3. Click the **Feature** button
4. Gallery now appears prominently on public page

### Copying an Event Code
1. Go to **Content > Moments**
2. Find your gallery
3. Click **Copy Code**
4. Code is copied to clipboard

### Changing a Video Status
1. Find the video in **Content > Videos**
2. Click the video card
3. Change status dropdown
4. Save changes

## Troubleshooting

### "Access Denied" Message
- Your role doesn't have permission for this feature
- Contact an administrator to update your role

### Can't See a Module
- Module isn't included in your role's access
- Contact an administrator if you need access

### Page Won't Load
- Check your internet connection
- Try refreshing the page
- Clear browser cache
- Contact technical support if issue persists

### Login Issues
- Ensure you're using the correct email
- Try resetting your password
- Contact an administrator for account issues

## Best Practices

### Content Management
- Always add descriptive titles
- Use consistent naming conventions
- Set appropriate visibility for sensitive content
- Review content before publishing

### Event Galleries
- Create galleries at least 24 hours before events
- Use memorable, short event codes
- Set clear start/end times
- Test the upload flow before the event

### Security
- Don't share your login credentials
- Log out when using shared devices
- Report suspicious activity immediately
