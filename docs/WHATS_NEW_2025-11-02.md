What's new — 2025-11-02

This document summarizes the admin and developer tooling added on 2025-11-02.

Highlights

- In-app Cloudflare D1 + R2 Admin Tools
  - SQL console at `/admin/db` for executing D1 queries and applying safe schema changes (use the **Apply Moments schema** button to create the Moments tables without Wrangler).
  - R2 storage browser at `/admin/storage` with list, upload, delete, and move/rename operations.

- Moments Gallery System
  - Public galleries endpoint: `/api/moments/galleries/public`
  - Idempotent schema apply endpoint (admin-only): `/api/admin/db/apply-moments`
  - Featured page (`/featured/manage`) can create/select a Moments gallery inline and link its capture page (`/moments/capture?galleryId=...`).

- Diagnostics & Auth
  - Public environment health probe: `/api/health/env` (reports presence of `DATABASE_URL`, D1 token, `JWT_SECRET`, etc.).
  - Login error messages now surface common misconfiguration errors (e.g. missing env vars or D1 connectivity problems).
  - Admin override via `ADMIN_EMAILS` env var for bootstrapping admin access before DB `is_admin` exists.

Quick verification

1. Ensure `.env.local` contains `DATABASE_URL`, `CLOUDFLARE_D1_API_TOKEN` or `CLOUDFLARE_API_TOKEN`, and `JWT_SECRET`.
2. Run `npm run dev`.
3. Confirm health: `http://localhost:3000/api/health/env` returns `ok: true`.
4. Apply schema: visit `/admin/db` and click **Apply Moments schema**.
5. Create/link gallery: `/featured/manage` -> create gallery -> select -> Save -> Open (should go to `/moments/capture?galleryId=...`).
